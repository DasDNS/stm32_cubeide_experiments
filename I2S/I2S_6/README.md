# STM32 I2S Audio Capture and UART Transmission

This project demonstrates how to capture audio data from an I2S-compatible microphone using STM32 and transmit the data over UART. The code is generated using STM32CubeMX and built using STM32CubeIDE.

## Features

- Captures audio input via I2S2 using DMA
- Transmits recorded 16-bit audio samples over UART (USART2)
- Uses DMA for efficient, non-blocking data transfer
- Designed for STM32 microcontrollers (tested with STM32L476RG)

## Hardware Requirements

- STM32 development board (e.g., STM32L4 Discovery, Nucleo series)
- I2S-compatible digital microphone (e.g., ICS43434, SPH0645LM4H)
- UART-to-USB interface (for PC serial monitoring)
- Optional: Oscilloscope or logic analyzer for signal verification

## Software Requirements

- STM32CubeIDE
- STM32CubeMX (for configuration)
- Serial terminal (e.g., PuTTY, TeraTerm) to view UART output

## System Overview

- **I2S2**: Configured as **Master Receiver** with 16 kHz sample rate and 16-bit data format
- **DMA**: Used to continuously transfer I2S audio data into a buffer
- **UART2**: Configured at 115200 baud rate to send audio buffer to a host PC
- **Callback**: `HAL_I2S_RxCpltCallback()` is used to reinitialize I2S DMA and send buffer contents

Main Execution Flow
System and peripherals initialized

Audio data is sent over UART

Usage
Connect the I2S microphone to SPI2 pins.

Flash the code to the STM32 board.

Connect UART2 TX to a USB-UART adapter.

Open a serial terminal at 115200 baud.

Observe raw audio data being streamed in hexadecimal or binary format.

Note: The UART output may require additional software or scripting to interpret/plot audio data.
