# STM32 I2S Audio Receiver with UART Transmission

This project demonstrates how to use an STM32 microcontroller to receive audio data via I2S using DMA and transmit it over UART. It utilizes the STM32 HAL library and CubeMX-generated boilerplate.

## Features

- 📡 **I2S (SPI2)**: Configured in **master receive** mode to capture 16-bit audio data at 16 kHz.
- 💾 **DMA**: Efficiently transfers incoming I2S data into a memory buffer without CPU intervention.
- 🔁 **UART (USART2)**: Sends the captured audio data buffer over UART using DMA.
- 💡 **Debug Output**: Prints "Hello World" every second over UART.
- 🔁 **GPIO & Interrupt Setup**: Button (B1) configured with interrupt handling.
- ⚠️ **Error Handler**: Custom error handler halts execution on failure.

## Hardware Requirements

- STM32 Nucleo board (or compatible STM32 board)
- ICS43434 or other I2S-compatible MEMS microphone (if used for real input)
- UART to USB converter (for viewing UART output on a PC)
- Optional: Logic analyzer or oscilloscope for debugging I2S

## File Structure

- `main.c`: Main application code.
- `stm32fxxx_hal_*.c/h`: HAL driver files (generated by CubeMX).
- `README.md`: This documentation.

## Usage

1. **Clone or download the project** to your STM32CubeIDE workspace.
2. **Connect your I2S microphone** to the SPI2/I2S2 interface.
3. **Open the project in STM32CubeIDE**.
4. **Build and flash the firmware** to your STM32 board.
5. **Open a serial monitor** (e.g., PuTTY, TeraTerm) at `115200 baud` to view UART output.

## How It Works

- I2S is initialized in `MX_I2S2_Init()` with 16-bit Philips format at 16 kHz.
- DMA starts transferring incoming I2S data into `data_i2s[]`.
- When the buffer is filled, the `HAL_I2S_RxCpltCallback()` function is triggered:
  - The content of `data_i2s[]` is transmitted over UART via DMA.
- A `printf("Hello World")` message is sent every second using `HAL_Delay()`.
